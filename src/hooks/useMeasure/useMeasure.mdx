# useMeasure

Hook that use a `ResizeObserver` to track measure of the an element.
You can register an element by using the returned callback ref.

```tsx
const MyComponent: React.FC = () => {
    const {
        // contain the current element dimension
        dimension,
        // a callback ref to register the element
        ref,
        // the actual measured element
        element,
        // function to manuallt trigger a measurement
        update,
    } = useMeasure();

    return <div ref={ref}>a div</div>;
};
```
