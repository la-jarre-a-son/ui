# useAnimationDuration

Managing in/out animation of conditionnaly rendered elements can be quite tricky as React will unmount the DOM node without waiting for the exit animation to end.
For this purpose, the `useAnimationDuration` allow to delay the unmounting of a React node for the duration of an animation.

## Usage

### Animation end callback

Pass the returned callback as either the `onTransitionEnd` or `onAnimationEnd` callback of the animated element.
You can also react to the end of the animation, or the end of the exiting or entering specificaly by passing the corresponding callbacks as an option.

```tsx
const Comp = ({ open = false }) => {
    // if 'open' become false, the 'show' will be set
    // to false once the animation end
    const [show, handleAnimationEnd] = useAnimationDuration(open, {
        // trigger each time the animation end
        onAnimationEnd: () => {},
        // trigger once entering is done
        onEntered: () => {},
        // trigger once exiting is done
        onExited: () => {},
    });

    return (
        show && (
            <div className="my-animation-class" onAnimationEnd={handleAnimationEnd}>
                conditionnaly rendered
            </div>
        )
    );
};
```

### Timer

You can also use a timer to manage the transition/animation duration.

```tsx
const Comp = ({ open = false }) => {
    // the 'show' flag will be set to false 300ms
    // after the 'open' flag become false
    const [show] = useAnimationDuration(open, {
        duration: 300,
    });

    return show && <div className="my-animation-class">conditionnaly rendered</div>;
};
```

## globally disable animations

In some cases you may wan't to not use any animation, for example, when running on environnements that do not support transition/animation end callback (like JSDom) or if the user [asked so](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion).
In those cases, you can globally disable the hook behaviour by using the `disableAnimation` or `enableAnimation` functions.
You can also know if the hook behaviour is currently enabled with the `isAnimationDisabled` function.

```ts
// MyComp.spec.tsx

describe('MyComp', () => {
    beforeAll(() => {
        // disable the hook behaviour. the 'show'
        // returned flag will be always directly
        // synchronized with the 'open' param
        disableAnimation();
    });

    afterAll(() => {
        enableAnimation();
    });

    it('conditionnaly render something', () => {
        // test the appearance/disapearance of something
    });
});
```
