# useStateMachine

State charts are a very solid way to describe a state.
By expressing all of the possible finite state and each event those that are managing, we ensure that no unexpected state combination / event handling will be thrown.
The `useStateMachine` hook is a very simple way do express a finite state machine.

## some definition

In the following documentation, we will use the terms below:

-   state: a string that represent a _finite_ state of our application
-   context: a variable of any type that can contain contextual values.
-   descriptor: the object that describe all ours states and state transitions.

## machine descriptor

The machine is described as an object whose each key is a possible state.

Each of those states will contain an object with the events handled by the state.

Each event will indicate ether the next state as a string, object or as a function returning the next state.

```ts

const descriptor = {
    // a state
    state1: {
        // an event with next state as a string
        EVENT1: "nextState",

        // next state as an obect with some context
        EVENT2: {
            state: "nextState",
            context: {
                username: "bob",
                age: 32,
            }
        }

        // next state depending on the function result
        EVENT3: () => {
            if (someThingToTestEventually()) {
                return "nextState"
            }
            return {
                state: "otherState",
                context: {
                    username: "bill",
                    age: 40,
                }
            }
        }
    },

    // another state
    state2: {
        // ...
    }
}

```

```tsx

const descriptor = {
    step1: {
        NEXT: "step2",
    },
    step2: {
        NEXT: "step3",
        PREV: "step1",
    },
    step3: {
        PREV: "step2",
        NEXT() {
            if (isValid()) {
                return "done"
            }
            return "error"
        },
    },
    error: {
        RETRY: "step1"
    }
    done: {}
};

// ...

const [{ state, context }, dispatch] = useStateMachine(descriptor)
```
