# useCreatePortal

Hook to facilitate the creation of React [portals](https://reactjs.org/docs/portals.html).
This will return a function that will create a portal for the given React node.

The portal will be created on client-side only.

```tsx
const MyComponent: React.FC = () => {
    const createPortal = useCreatePortal();

    return createPortal(<div>In a portal</div>);
};
```

## Root element

By default, the portal will be attached on the body. But you can define a node as a second argument of the returned `createPortal` function.

```tsx
const MyComponent: React.FC = () => {
    const createPortal = useCreatePortal();

    return createPortal(<div>In a portal</div>, myCustomAnchorElement);
};
```

## Disabling the portal

It is sometime usefull to conditionnaly disabling the portal behaviour.
You can simply do it by providing a boolean as a parameter of the hook.

```tsx
const MyComponent: React.FC = () => {
    // disable the portal beviour
    const createPortal = useCreatePortal(false);

    return createPortal(<div>Not in a portal</div>);
};
```
