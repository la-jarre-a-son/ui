# useOnScroll

Hook that raise a flag however the page is scrolled.

It accept an optionnal `offset` number as an option.

```tsx
const isScrolled = useOnScroll(); // true when we scroll

const isOffsetScolled = useOnScroll({
    offset: 50,
}); // true when we scroll past 50px
```
